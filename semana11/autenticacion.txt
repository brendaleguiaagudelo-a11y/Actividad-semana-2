El login permite identificar a un usuario antes de darle acceso a determinadas funciones de una aplicación. Algunas rutas deben estar protegidas porque contienen información privada o permiten realizar acciones importantes. De esta manera se evita que personas no autorizadas accedan al sistema. No se deben exponer públicamente contraseñas, documentos de identidad, direcciones, teléfonos, tokens, claves de API ni otros datos sensibles. Esto ayuda a proteger la privacidad y la seguridad de la comunidad.
