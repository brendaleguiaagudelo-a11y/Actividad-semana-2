Al ejecutar node server.js se inicia el servidor Node.js y queda esperando solicitudes.

En la terminal aparece el mensaje:
"Servidor ejecutándose en puerto 3000".

Cuando se visita la ruta /estado el servidor responde un objeto JSON con la información del estado del servicio.

Respuesta obtenida:

{
  "estado": "Servidor funcionando",
  "servicio": "API comunitaria"
}
